## Selected work

### [Praxis — Hardware knowledge for AI assistants](https://github.com/Iheb-AG/praxis)

A Python compiler and MCP toolkit that turns hardware references into source-grounded knowledge for AI coding assistants.

- Indexed Markdown bundles with source provenance and dependency-aware, vectorless retrieval.
- Three read-only MCP tools for hardware documentation and exact pin/net lookup.
- Docker packaging, isolated firmware builds, ELF checks, and scoped STM32F407 demonstrations.

**Python · MCP · Docker · STM32**  
*Experimental alpha; supported workflows and validation limits are documented in the repository.*

### [CARLA–STM32–ATmega328P — HIL prototype](https://github.com/Iheb-AG/hil-testbench-carla-stm32-atmega328p)

My **PFA at ISI Ariana**, exploring automotive telemetry and embedded classification through a simulation-to-controller architecture.

- CARLA telemetry and scenario-data generation with 23 measurement features.
- Temporal CNN training and ONNX export, serial framing, and embedded driver foundations.
- Intended CAN-connected STM32/ATmega328P pipeline; end-to-end hardware integration remains unfinished.

**C · Python · CARLA · STM32 · ATmega328P · CAN · TensorFlow / ONNX**

### [Hand Tremor Stabilizer — STM32 motion-control prototype](https://github.com/Iheb-AG/Hand-Tremor-Stabilizer)

An inertial-sensing and servo-control prototype on STM32L475.

- LSM6DSL acquisition over I2C and complementary pitch/roll filtering.
- Orientation estimates mapped to three PWM channels, with inertial telemetry over UART.

**C · STM32 HAL · I2C · PWM · UART**
